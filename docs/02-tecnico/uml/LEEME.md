# Diagrama UML

El UML definitivo se preparará cuando las clases y sus firmas estén integradas y verificadas. Debe representar la herencia de las cargas, la agregación de cargas en `Negocio`, la composición con `Medidor` y la asociación con `Mercado`.

Antes de preparar el PDF, comparar clases, firmas, visibilidad y multiplicidades con el código integrado. Exportar la versión validada a PNG o PDF para el informe.
